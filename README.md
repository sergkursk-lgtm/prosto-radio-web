# Просто Радио — веб-версия (PWA)

Веб-приложение на том же каталоге, что и Android-версия: 2338 российских станций
лежат файлом и читаются локально. Список, поиск, жанры и регионы работают без
интернета. Через сеть идут только аудиопоток и логотип станции.

## Файлы

```
index.html              разметка
styles.css              оформление: те же цвета и объёмные кнопки, что в приложении
app.js                  вся логика: каталог, поиск, избранное, плеер
stations.json           каталог станций, 950 КБ
manifest.webmanifest    описание для установки на телефон
sw.js                   сервис-воркер: кэш оболочки и каталога
icons/                  иконки 192, 512 и 180 для iPhone
```

## Запуск локально

```
cd radio-web
python3 -m http.server 8099
```

Открыть `http://localhost:8099`. На localhost сервис-воркер работает и без https.

## Главное, что нужно знать перед публикацией

**Больше половины станций вещают по `http`, а не `https`.** В каталоге таких
1341 из 2338 — 57%. Например, Европа Плюс, Ретро FM, Вести FM, ROCK FM.

Браузеры считают `http`-аудио на `https`-странице небезопасной вставкой и
**блокируют его, даже не пытаясь подключиться**. Поэтому выбор площадки —
это выбор между двумя режимами:

### Вариант А: раздать по http

Всё играет сразу, ничего дорабатывать не нужно.

Минус: сервис-воркер работает только в защищённом контексте, то есть по http
его не будет. Каталог останется рабочим за счёт обычного кэша браузера, но
гарантированного офлайна не будет. На iPhone приложение всё равно добавляется
на экран «Домой» и играет в фоне.

### Вариант Б: раздать по https (рекомендуется)

Нужен сервис-воркер и офлайн — тогда обязателен **прокси для потоков**: сервер
принимает `http`-поток станции и отдаёт его клиенту уже по `https`.

Схема простая:

```
клиент → https://ваш-домен/stream?url=<адрес станции>  →  сервер → http://станция
```

В `app.js` за это отвечает константа `PROXY_BASE` — в начале блока работы с
потоками. Пустая строка означает работу напрямую. Чтобы включить прокси, впишите
адрес развёрнутого воркера:

```js
const PROXY_BASE = 'https://ваш-воркер.ваш-аккаунт.workers.dev';
```

Готовый прокси лежит в `worker/stream-proxy.js` — это Cloudflare Worker,
разворачивается с бесплатного тарифа за пару минут. Инструкция в начале файла.
Он принимает только `http`-адреса, не ходит в локальную сеть и в служебные
диапазоны, поэтому не превращается в открытый релей.

### Прокси нужен не только для http-потоков

Часть станций вещает по https, но **на нестандартных портах** — «Маруся ФМ»,
например, на 8000 и 9433. Мобильные операторы такие порты часто режут: по Wi-Fi
станция играет, в мобильной сети — нет. Прокси снимает и это: клиент общается
только с воркером по 443, а тот идёт за потоком со своей стороны.

### Что приложение делает само, без прокси

- **Перебирает источники.** У станции в каталоге часто несколько записей с разными
  хостами. Если один адрес не открылся, приложение молча берёт следующий —
  сначала напрямую, потом через прокси (если он задан), потом другую запись.
- **Не зависает на «Подключение…».** Если оператор не отказывает в соединении,
  а молча глотает пакеты, через 10 секунд без данных приложение уходит на
  следующий адрес.
- **Называет причину.** Вместо прежнего «недоступна по защищённому соединению»
  на любую ошибку — конкретика: нет связи с потоком, не открылся порт 8000
  (возможно, блокирует оператор), станция вещает по http и нужен прокси,
  формат не поддерживается браузером.

### Сколько станций играет на https без прокси

Проверено на выборке: если подставить `https` в адрес целиком, с портом и путём,
**отвечают около 29%** http-станций. Остальные вещают с нестандартных портов,
где TLS не поднят, и до них нужен прокси.

Итого на https-хостинге вроде GitHub Pages:

| Хостинг | Играет | Офлайн | Установка на iPhone |
|---|---|---|---|
| http | все 2338 | нет (сервис-воркеру нужен https) | да, но без офлайна |
| **https без прокси** (GitHub Pages) | **примерно 1400 из 2338** | да | да |
| https с прокси | все 2338 | да | да |

Точную цифру заранее не скажет никто: часть станций то отвечает, то нет,
а некоторые переезжают. Если приложение пишет «нужен прокси» или называет
заблокированный порт — станции действительно нужен воркер из
`worker/stream-proxy.js`.

## Установка на iPhone

1. Открыть адрес в **Safari** (именно Safari — Chrome на iOS этого не умеет).
2. Кнопка «Поделиться» → **«На экран Домой»**.
3. Запускать приложение **с иконки на экране**, а не из вкладки браузера.

### Что будет работать в фоне

| Возможность | Как работает |
|---|---|
| Звук при заблокированном экране | да, пока играет элемент `<audio>` |
| Плеер на экране блокировки | да, через Media Session API |
| Кнопки на наушниках | да, play/pause и переключение |
| Переключение станций с блокировки | да, ⏮ ⏭ |
| Звук при сворачивании Safari | да, если запущено с иконки |

### Чего на iOS не будет

- **Автовоспроизведение при запуске.** Safari разрешает звук только после
  касания. Поэтому приложение открывается с уже выбранной станцией и надписью
  «Нажмите ▶, чтобы продолжить» — одно касание, и эфир идёт.
- **Спектра и визуализаций.** Web Audio API на iOS засыпает в фоне.
- **Гарантированной работы, если открывать из вкладки, а не с иконки.**
  Вкладку iOS выгружает агрессивнее.

Это ограничения платформы, а не приложения. Android-версия всего этого лишена.

## Что уже проверено

- каталог читается, список из 2338 станций, поиск, жанры и регионы — без сети
- кириллица в поиске: «маруся» → 2 станции, «ретро» → 60, регистр не важен
- воспроизведение http- и https-потоков, переключение ⏮ ⏭ по очереди
- избранное сохраняется в localStorage
- регион определяется по часовому поясу браузера, вручную меняется из списка
- сервис-воркер регистрируется, оболочка кэшируется
- ландшафт: список слева, плеер справа — как в Android-версии

## Известные ограничения

- **Названия регионов в каталоге разнородны**: «Moscow», «Москва» и «Moskow» —
  три разных записи об одном городе. Уточнения в скобках объединяются
  автоматически, но кириллица и латиница остаются раздельными.
- **Логотипы есть не у всех станций.** Часть вещателей не отдаёт иконку ни по
  одному адресу — тогда показывается заглушка. Так же ведёт себя Android-версия.
- **Каталог застывший.** Чтобы обновить список, замените `stations.json` и
  поднимите `VERSION` в `sw.js`, иначе кэш отдаст старый файл.
